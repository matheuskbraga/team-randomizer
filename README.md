# Sorteador e Divisor de Grupos em Python

Script simples desenvolvido em Python para dividir automaticamente uma quantidade arbitrária de alunos em grupos equilibrados e sorteados de forma aleatória.

## Funcionalidades

- **Sorteio Aleatório:** Embaralha a lista de participantes para garantir divisões justas e imparciais.
- **Distribuição Balanceada:** Lida com números ímpares e sobras, mantendo a diferença de integrantes entre equipes no mínimo possível.
- **Fácil Customização:** Permite definir tanto a quantidade desejada de grupos quanto o limite máximo de membros por equipe.

## Pré-requisitos

- Python 3.10 ou superior (utiliza apenas a biblioteca nativa `random`, dispensando instalações externas).
